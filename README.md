# PureHome Add-ons

Repositório de add-ons do Home Assistant da PureHome.

| Add-on | Função |
|---|---|
| [PureHome Agent](purehome_agent) | Conecta o Home Assistant do cliente ao Portal PureHome (saúde, backup, atualização e busca de dispositivos). Só faz conexões de saída. |

Para instalar: **Configurações → Add-ons → Loja de add-ons → ⋮ → Repositórios** e adicione
`https://github.com/brmilanib/purehome-addons`.
